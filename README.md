# داریوش — GitHub APK Builder

این مخزن یک نسخه مینیمال اختصاصی را روی سورس **v2rayNG 2.2.6 / Xray** می‌سازد.

## رفتار برنامه

- اجرای اول: فقط یک کادر برای وارد کردن لینک کانفیگ/اشتراک سازگار با v2rayNG نمایش می‌دهد.
- بعد از ثبت لینک، اندروید یک‌بار مجوز VPN را می‌خواهد.
- از اجرای دوم به بعد هیچ صفحه‌ای باز نمی‌شود؛ لمس آیکون فقط VPN را روشن/خاموش می‌کند.
- آیکون سفید شیشه‌ای = قطع.
- آیکون سبز = Xray واقعاً شروع شده است.
- رابط اصلی v2rayNG در Launcher نمایش داده نمی‌شود.
- نام نمایش‌داده‌شده زیر آیکون: `داریوش`
- Package ID: `com.mediatelecom.onetapvpn`
- خروجی Workflow: APK نصب‌شدنی `arm64-v8a` مناسب دستگاه‌های اندرویدی جدید.

## ساخت APK در GitHub

1. یک Repository جدید بسازید.
2. محتوای این پوشه را در ریشه Repository آپلود کنید.
3. وارد تب **Actions** شوید.
4. Workflow با نام **Build OneTap VPN APK** را اجرا کنید (`Run workflow`).
5. پس از موفق شدن Build، در پایین همان Run از بخش **Artifacts** فایل `OneTapVPN-arm64-v8a` را بگیرید.
6. ZIP Artifact را باز کنید و `OneTapVPN-arm64-v8a.apk` را روی گوشی/تبلت نصب کنید.

## نکته‌های اندروید

- Android فقط یک VPN فعال را هم‌زمان اجازه می‌دهد؛ هنگام تست، v2rayNG یا VPN دیگری را خاموش کنید.
- مجوز VPN در اجرای اول توسط خود Android نمایش داده می‌شود و قابل حذف نیست.
- سرویس VPN برای پایداری از Foreground Service استفاده می‌کند؛ Android ممکن است نوتیفیکیشن سرویس VPN را نمایش دهد.
- تغییر آیکون Launcher با دو `activity-alias` انجام می‌شود. بعضی Launcherها تغییر رنگ را با تأخیر کوتاه Refresh می‌کنند؛ منطق اتصال مستقل از این تأخیر است.

## تغییر لینک بعداً

نسخه 1.0 عمداً هیچ صفحه تنظیماتی بعد از راه‌اندازی ندارد. برای وارد کردن لینک جدید، ساده‌ترین روش پاک‌کردن Data برنامه یا نصب مجدد است. در نسخه بعدی می‌توان Long-press/کد مخفی برای تعویض کانفیگ اضافه کرد بدون ایجاد صفحه معمولی.
